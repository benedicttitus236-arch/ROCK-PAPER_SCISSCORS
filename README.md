# 🎮 Rock Paper Scissors

A simple **Rock Paper Scissors** game built using **Python**.
The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice.

## ✨ Features

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors
* 🤖 Computer makes a random choice
* 🏆 Automatically determines the winner
* 🔄 Option to play multiple rounds
* ❌ Handles invalid choices

## 🛠️ Technologies Used

* **Python**
* `random` module

## ▶️ How to Run

### 1. Clone the repository

git clone https://github.com/benedicttitus236-arch/ROCK-PAPER_SCISSCORS.git

### 2. Open the project folder

cd ROCK-PAPER_SCISSCORS

### 3. Run the program

python "rock, paper, scissor.py"

## 🎯 How to Play

When the game starts, enter:

```text
R → Rock
P → Paper
S → Scissors
```

The computer will randomly select its choice.

The rules are:

```text
Rock     beats Scissors
Scissors beats Paper
Paper    beats Rock
```

If both the player and computer choose the same option, the result is a **Tie**.
